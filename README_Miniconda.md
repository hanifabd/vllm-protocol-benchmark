1. Download the InstallerGet the official Miniconda installation script using wget:bash
```bash
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
```

2. Run the ScriptExecute the script to start the installer:bash
```bash
bash Miniconda3-latest-Linux-x86_64.sh
```

Follow the prompts on the screen.Press Enter to review the license agreement and type yes to accept it.Confirm your installation directory (press Enter for the default location).Type yes when asked to initialize Conda.

3. Apply ChangesReload your shell to apply the changes without closing the window:bash
```bash
source ~/.bashrc
```

4. Verify InstallationEnsure it works by checking the version number:bash
```bash
conda --version
```
